## 二、HSK 3.0 标准对齐（2026最新版）

根据2025年中国教育部最终定稿的HSK 3.0标准，教材必须严格对齐以下词汇体系：

| HSK等级 | 累计词汇量 | 本级新增 | 对应CEFR | Z Turns Chinese教材对应 |
|---------|-----------|---------|---------|------------------------|
| **HSK 1** | **300词** | 300 | A1 | **Book 1: 零基础入门** |
| **HSK 2** | **497词** | 197 | A2 | **Book 2: 日常会话** |
| **HSK 3** | **988词** | 491 | B1 | **Book 3: 职场中文** |
| HSK 4 | 1,978词 | 990 | B2 | （Phase 2扩展）|
| HSK 5 | 3,557词 | 1,579 | C1 | （Phase 3扩展）|
| HSK 6 | 5,334词 | 1,777 | C2 | （未来规划）|
| HSK 7-9 | 10,896词 | 5,562 | C2+ | （未来规划）|

> **来源验证：** [HSK 3.0 2026词汇标准](https://hskstory.com/guides/hsk-30-vocabulary-complete) | [Khanji School HSK 3.0解读](https://khanjischool.com/blog/chinese/new-hsk-30-2026-vocabulary-levels-exams-and-official-textbooks)

**关键变化提醒：** HSK 3.0（2026版）相比2021草案大幅精简——HSK 1从500词降至300词，HSK 2从1,272词降至497词。这意味着你的Book 1和Book 2的词汇控制更容易，每课新词数量更加合理。HSK 3.0还新增了当代日常词汇如「扫码」「充值」「电商」「民宿」等，非常适合职场场景教材。

## 四、GetNotes MCP 数据管线（核心数据源）

这是整个系统的"燃料供给线"。你有100+小时课程录音和Markdown笔记，通过GetNotes MCP Server可以让AI直接调用知识库。

**GetNotes MCP Server能力：**

| 能力 | 说明 | 在本系统中的用途 |
|------|------|----------------|
| AI搜索知识库 | 按关键词/语义搜索，返回AI合成答案 + 引用来源 | 根据教材主题搜索相关教学片段 |
| 原始内容召回 | 返回相关笔记和文件的原始文本 | 获取真实课堂对话的原文 |
| 多知识库支持 | 可配置多个知识库，AI自动选择最相关的 | 按话题/难度分不同知识库 |
| 速率限制 | QPS < 2，总请求 < 5000 | 需在管线中做请求队列管理 |
| 自动重试 | 5xx错误自动重试 | 网络稳定性保障 |

> **来源：** [GetNotes MCP Server](https://mcpmarket.com/server/get-notes)

## 五、四层逐字对照翻译引擎（核心差异化模块）

这是整个产品最独特的卖点。市面上没有任何中文教材同时提供这四层对照。

**技术管线：**

```
输入句子: "你想吃什么？"
         │
         ▼
┌─────────────────────────────────────────────────────────────────┐
│  Stage 1: 中文分词 (jieba / spaCy-pkuseg)                       │
│  ─────────────────────────────────────────                       │
│  "你想吃什么？" → ["你", "想", "吃", "什么"]                     │
│                                                                  │
│  技术选型: spaCy + pkuseg (神经网络分词，准确率 > jieba)          │
│  参考: hskstory.com 使用 spacy-pkuseg + pypinyin 管线            │
└──────────────────────────────┬──────────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────────┐
│  Stage 2: 拼音标注 (pypinyin)                                    │
│  ────────────────────────────                                    │
│  ["你", "想", "吃", "什么"]                                      │
│     ↓      ↓     ↓     ↓                                        │
│  ["nǐ", "xiǎng", "chī", "shénme"]                              │
│                                                                  │
│  多音字处理: pypinyin.Style.TONE + 自定义词典补充                  │
│  例外处理: "什么" → "shénme" (非 "shíme")                        │
└──────────────────────────────┬──────────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────────┐
│  Stage 3: 逐词英文对照 (LLM + 校验词典)                          │
│  ─────────────────────────────────────────                       │
│  ["你", "想", "吃", "什么"]                                      │
│     ↓      ↓     ↓     ↓                                        │
│  ["you", "want", "eat", "what"]                                  │
│                                                                  │
│  流程: LLM生成 → HSK词典交叉校验 → 人工确认高频词固定翻译         │
│  维护: 核心300词建立固定翻译映射表，保证全书一致性                  │
└──────────────────────────────┬──────────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────────┐
│  Stage 4: 自然英文翻译 (LLM)                                     │
│  ────────────────────────────                                    │
│  "你想吃什么？" → "What would you like to eat?"                  │
│                                                                  │
│  要求: 符合英语母语者表达习惯，非直译                             │
```
