# Delivery status

Status: **design reference only — not production-ready and not approved for paid delivery**.

This repository currently contains six independent technical proposals. It does not contain a single selected architecture, executable implementation, automated acceptance suite, content provenance checks, copyright clearance, or a reproducible release artifact.

Before describing the project as production-ready or accepting payment, require all of the following:

1. Select and version one authoritative specification.
2. Implement an executable end-to-end path with deterministic inputs and outputs.
3. Add factual-source, licensing, copyright, privacy, and human-review gates.
4. Validate generated material against an explicit curriculum/version and publish the evidence.
5. Run repeatable tests and produce a versioned release artifact with rollback instructions.

Until these gates pass, examples and provider comparisons are exploratory material only. They are not evidence that a textbook is accurate, lawful, safe for learners, or ready for customer delivery.

# 交付状态

状态：**仅供方案研究——尚未达到生产级，也未批准用于收费交付**。

本仓库目前包含六套彼此独立的技术方案，尚无唯一权威架构、可执行实现、自动验收、内容来源与版权门禁，亦无可复现发布制品。

在使用“生产级”表述或接受付费前，至少必须：

1. 选定并版本化一套权威方案；
2. 实现输入、输出可复现的端到端链路；
3. 建立事实来源、许可、版权、隐私和人工复核门；
4. 按明确的课程标准与版本验证内容，并公开验证证据；
5. 运行可重复测试，生成带回滚说明的版本化发布制品。

上述门槛通过前，示例和模型对比仅属于探索资料，不能证明教材准确、合法、适合学习者或可向客户交付。
