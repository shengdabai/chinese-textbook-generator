# 中文教材生成工具 - 技术方案 v2.0

## 0. 产品愿景与核心价值

### 0.1 一句话定义
> 将真实课堂素材自动转化为**结构化、可出版、可持续**的中文教学教材

### 0.2 核心问题解决
| 问题 | 解决方案 | 关键特性 |
|---|---|---|
| 素材散乱难复用 | 统一入库+切片管理 | 来源追溯、版本控制 |
| 隐私信息难清理 | 多层检测+人工终审 | PII漏检率<0.1% |
| 生成风格不统一 | 句型记忆库+模板约束 | 复用率>70% |
| 课次之间无衔接 | 课程图谱+多线并行 | 多课程线统一规划 |
| 导出格式不专业 | 按级别多模板+版本绑定 | PDF/DOCX/EPUB直出 |
| 新词难度失控 | 软限制+警告机制 | 参考值提示，人工决策 |

### 0.3 产品定位

### 1.2 服务拆分矩阵
| 服务 | 核心职责 | 输入 | 输出 | 技术栈 |
|---|---|---|---|---|
| ingest-service | 导入、切片、元数据标注 | 源文件 | raw_chunks | FastAPI |
| privacy-service | PII检测、脱敏、人工审核流 | raw_chunks | safe_chunks | FastAPI + NER |
| asset-service | 词汇/句型/错误提取、入库 | safe_chunks | assets | FastAPI |
| generation-service | 按课程约束生成教材 | assets + 课程图谱 | lesson_versions | FastAPI + LLM |
| qa-service | 隐私+一致性校验 | lesson_versions | qa_reports | FastAPI |
| export-service | 模板渲染、多格式导出 | lesson_version + 模板 | PDF/DOCX/EPUB | FastAPI + WeasyPrint |

### 1.3 技术选型对比
| 类别 | 推荐方案 | 备选方案 | 选型依据 |
|---|---|---|---|
| 后端框架 | FastAPI | NestJS | Python NLP生态更成熟 |
| 前端 | Next.js + React | React + Vite | 后台系统完整生态 |
| 数据库 | PostgreSQL | MySQL | JSONB支持+成熟事务 |
| 缓存/队列 | Redis + Celery | Redis + BullMQ | 异步任务成熟方案 |
| 向量检索 | pgvector (V2再上) | ES/OpenSearch | MVP简化复杂度 |
| PDF导出 | WeasyPrint | Puppeteer | 无头浏览器方案 |
| EPUB导出 | python-epubbuilder | - | 成熟库 |

### 2.2 核心数据表
```sql
-- 原始素材切片表
CREATE TABLE raw_chunks (
    chunk_id      UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    session_id    UUID NOT NULL REFERENCES sessions(session_id),
    raw_text      TEXT NOT NULL,
    speaker_role  VARCHAR(20),  -- teacher/student/unknown
    created_at    TIMESTAMP DEFAULT NOW()
);

-- 脱敏语料表
CREATE TABLE safe_chunks (
    safe_chunk_id   UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    source_chunk_id UUID REFERENCES raw_chunks(chunk_id),
    clean_text      TEXT NOT NULL,
    topic_tags      TEXT[],      -- 主题标签
    function_tags   TEXT[],      -- 功能标签
    approved        BOOLEAN DEFAULT FALSE,
    approved_by     UUID,
    approved_at     TIMESTAMP,
    created_at      TIMESTAMP DEFAULT NOW()
);

-- 句型记忆库（核心资产）
CREATE TABLE phrase_memory (
    phrase_id   UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    en_text     VARCHAR(500) NOT NULL,  -- 英文表达
    zh_text     VARCHAR(500) NOT NULL,  -- 中文表达
    pinyin      VARCHAR(500),           -- 拼音
    gloss       VARCHAR(500),            -- 英文释义
    level       VARCHAR(10),            -- CEFR: A1/A2/B1
    function    VARCHAR(100),           -- 交际功能
    first_lesson_id UUID,                -- 首次出现课次
    version     INTEGER DEFAULT 1,
    created_at  TIMESTAMP DEFAULT NOW(),
    UNIQUE(en_text, version)
);

-- 词汇账本
CREATE TABLE vocab_ledger (
    vocab_id    UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    zh_word     VARCHAR(100) NOT NULL,
    pinyin      VARCHAR(200),
    en_meaning  VARCHAR(500),
    level       VARCHAR(10),
    part_of_speech VARCHAR(20),
    version     INTEGER DEFAULT 1,
    UNIQUE(zh_word, version)
);

-- 课程图谱表
CREATE TABLE courses (
    course_id   UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    title       VARCHAR(200) NOT NULL,
    target_level VARCHAR(10),  -- A1/A2/B1
    description TEXT,
    created_at  TIMESTAMP DEFAULT NOW()
);

CREATE TABLE units (
    unit_id     UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    course_id   UUID REFERENCES courses(course_id),
    title       VARCHAR(200),
    seq_order   INTEGER
);

CREATE TABLE lessons (
    lesson_id   UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    unit_id     UUID REFERENCES units(unit_id),
    title       VARCHAR(200),
    can_do      TEXT,           -- ACTFL Can-Do
    new_vocab_limit INTEGER,    -- 新词上限
    recycled_vocab TEXT[],      -- 复现词汇
    seq_order   INTEGER
);

-- 课次版本表
CREATE TABLE lesson_versions (
    version_id       UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    lesson_id        UUID REFERENCES lessons(lesson_id),
    content_json     JSONB NOT NULL,  -- 完整课次内容
    status           VARCHAR(20),     -- draft/qa_passed/published
    generated_from   UUID[],          -- 引用的safe_chunk_ids
    qa_report_id     UUID,
    prompt_version   VARCHAR(50),
    created_by       UUID,
    created_at       TIMESTAMP DEFAULT NOW()
);

-- QA报告表
CREATE TABLE qa_reports (
    report_id        UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    version_id       UUID REFERENCES lesson_versions(version_id),
    privacy_score    DECIMAL(5,2),    -- 隐私安全分
    consistency_score DECIMAL(5,2),   -- 一致性分数
    issues           JSONB,           -- 问题列表
    passed           BOOLEAN,
    reviewed_by      UUID,
    reviewed_at      TIMESTAMP,
    created_at       TIMESTAMP DEFAULT NOW()
);

-- 导出记录表
CREATE TABLE exports (
    export_id    UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    version_id   UUID REFERENCES lesson_versions(version_id),
    format       VARCHAR(20),        -- pdf/docx/epub/csv
    file_path    VARCHAR(500),
    file_hash    VARCHAR(64),         -- SHA256用于验证
    created_at   TIMESTAMP DEFAULT NOW()
);
```

### 4.3 句型冲突解决策略
| 场景 | 策略 | 执行动作 |
|---|---|---|
| 同英文→不同中文 | 主句型+别名 | 保留主句型，其他标记为别名 |
| 同中文→不同英文 | 主表达+扩展 | 保留主表达，扩展需审核 |
| 相似但不同功能 | 分离存储 | 按功能分开，不可合并 |

### 12.2 技术限制说明
| 限制项 | 说明 | 应对方案 |
|---|---|---|
| LLM调用成本 | 按token计费 | 优化Prompt减少token、缓存复用 |
| 生成内容不确定性 | 同一输入可能不同输出 | 锁定模板+句型库约束 |
| PII检测局限性 | 无法100%覆盖所有变体 | 人工审核门禁强制执行 |
| 向量检索暂不上 | V1简化架构 | V2再引入pgvector |
