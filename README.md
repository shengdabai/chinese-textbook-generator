# Chinese Textbook Generator - Technical Specifications

A collection of technical specification documents for building AI-powered Chinese textbook generation tools, evaluated across 6 major LLM providers.

## Overview

This repository contains detailed technical plans for creating an automated Chinese textbook generation system. Each document provides a complete implementation blueprint including architecture, prompt engineering strategies, and output formatting for a specific LLM provider.

## Supported LLM Providers

| Provider | Model | Document |
|----------|-------|----------|
| Anthropic | Claude | `Claude中文教材生成工具技术方案.md` |
| OpenAI | GPT-5.4 Pro | `GPT5.4pro 中文教材生成工具技术方案.md` |
| Google | Gemini | `Gemini中文教材生成工具技术方案.md` |
| xAI | Grok | `Grok中文教材生成工具技术方案.md` |
| Moonshot | Kimi | `Kimi中文教材生成工具技术方案.md` |
| MiniMax | MiniMax | `Minimax中文教材生成工具技术方案.md` |

## Key Features

- **Multi-provider comparison** - Evaluate which LLM best suits textbook generation needs
- **Complete architecture design** - From prompt engineering to output formatting
- **Chinese language optimized** - Purpose-built for Chinese educational content
- **Production-ready specs** - Includes API integration, error handling, and scaling considerations

## Use Cases

- Comparing LLM capabilities for educational content generation
- Building a Chinese textbook authoring pipeline
- Understanding prompt engineering for structured educational output
- Selecting the optimal LLM provider for Chinese NLP tasks

# 中文教材生成工具 - 技术方案

基于 6 大主流 LLM 提供商的 AI 中文教材自动生成工具技术方案文档合集。

## 概述

本仓库包含构建自动化中文教材生成系统的详细技术方案。每份文档提供了完整的实施蓝图，包括系统架构、提示词工程策略和输出格式设计。

## 支持的 LLM 提供商

| 提供商 | 模型 | 文档 |
|--------|------|------|
| Anthropic | Claude | `Claude中文教材生成工具技术方案.md` |
| OpenAI | GPT-5.4 Pro | `GPT5.4pro 中文教材生成工具技术方案.md` |
| Google | Gemini | `Gemini中文教材生成工具技术方案.md` |
| xAI | Grok | `Grok中文教材生成工具技术方案.md` |
| Moonshot | Kimi | `Kimi中文教材生成工具技术方案.md` |
| MiniMax | MiniMax | `Minimax中文教材生成工具技术方案.md` |

## 主要特点

- **多模型对比** - 评估哪个 LLM 最适合教材生成需求
- **完整架构设计** - 从提示词工程到输出格式化
- **中文优化** - 专为中文教育内容设计
- **生产级方案** - 包含 API 集成、错误处理和扩展性考虑

## 适用场景

- 对比不同 LLM 在教育内容生成方面的能力
- 构建中文教材自动化编写流水线
- 学习结构化教育输出的提示词工程
